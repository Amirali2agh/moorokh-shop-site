# Design
The demo uses a soft rose-and-white palette with a deep berry announcement bar, white RTL header, blush hero, photo-based category shortcuts, selected-products shelf, and responsive product grid. Rounded controls and warm pink surfaces give it a softer beauty-store feel while preserving the catalog flow. Cards show brochure product photography, a key specification, and “استعلام قیمت” because the source brochure contains no prices. Product details expose brochure-derived claims with a source/verification note. Browse → details → local-only selection-list flow is simulated; no order or message is sent. CSS tokens are in `public/shop.css`.
